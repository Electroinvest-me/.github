# Electroinvest

Open-source tooling by Electroinvest.

## 🔐 SecureAccess — cross-platform OpenConnect VPN client

A free, simple GUI VPN client for **Ivanti / Pulse Connect Secure** (and everything
else OpenConnect speaks) on **macOS, Windows x64 and Windows ARM64**.
Install it, add a connection, click **Connect** — the VPN engine and drivers are
set up for you.

- **Repo:** https://github.com/Electroinvest-me/electroinvest-secureaccess
- **Download:** https://github.com/Electroinvest-me/electroinvest-secureaccess/releases
- **License:** GPL-3.0

Highlights: native Windows ARM64 build, cert-pinning with presets, 2FA prompt,
saved passwords in the OS secret store, system-tray status, full-tunnel routing.
